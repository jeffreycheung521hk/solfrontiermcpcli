## Claude Code specifics

- Begin each task card by writing a short plan in your first message (the card's acceptance list,
  the files you will create or edit), then implement immediately. Do not enter plan mode and do
  not wait for approval: these sessions often run unattended overnight.
- Commit after each green step, not at the end.
- When the human is testing with Claude Desktop or Phantom, ask for the exact stderr lines and
  the audit-log tail rather than guessing.
